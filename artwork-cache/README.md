# Third-party artwork references

This directory is a **URL-only character illustration index**, not a mirror of third-party artwork. Each `<pack>/<canonical-slug>/<url-sha256>.json` records the original HTTPS image URL, contextual source/post URL, caption and supplied credit. A caption is not necessarily a verified artist credit; anonymous upload metadata is not authorship.

The repository's software LICENSE does not grant rights to the referenced third-party images, characters or artwork. Copyright and other rights remain with their respective holders. Attribution is not permission to redistribute. Images are displayed from their original hosts in the character-research interface, subject to applicable source terms and rights; the index neither downloads nor rehosts image files. Source availability may change, and offline display is not guaranteed.

Only JSON reference records are intended for version control. Do not add image binaries, copies of source pages, credentials, private URLs, or other unrelated files. Entries are limited to 30 per character, deduplicated by normalized direct URL, and published as new files by Sweetiebot's scoped pony publication queue. Respect artist and source removal requests by removing the relevant reference record. The existing biography and curated artwork array remain independent.

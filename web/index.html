05 · Hosted web publishing

Deploy Kefania's web authentication

Separate from local PR drafting. Host Kefania's existing OAuth MCP publisher on AWS App Runner so ChatGPT can publish finished branches as codex-pony[bot]. AWS usage is billed.

Configure AWS deployment

Sign in locally with AWS CLI first. Create an App Runner GitHub source connection, put the GitHub OAuth secret and App PEM in AWS Secrets Manager, and grant the App Runner instance role access to those two secrets. Enter ARNs, never private keys. See hosting instructions.

Once AWS reports RUNNING, activate the service's assigned HTTPS origin. If a request timed out, inspect App Runner before retrying to avoid duplicate services.
